# SOC 2 Readiness Assessment — NorthLedger Technologies (Fictitious SaaS Company)

A complete mock SOC 2 Type II readiness assessment, built to demonstrate 
GRC (Governance, Risk & Compliance) documentation skills, including control 
matrix development, gap analysis, and remediation planning.

**Status:** ✅ Complete (simulated readiness assessment)

---

## 🎯 Project Purpose

This project simulates the work performed during a SOC 2 Type II readiness 
assessment — the phase that typically precedes a formal audit by a licensed 
CPA firm. It demonstrates the ability to:

- Translate Trust Services Criteria (TSC) into specific, auditable controls
- Identify realistic control gaps and rate associated risk
- Write actionable remediation plans with ownership and timelines
- Document evidence in a way that would hold up to auditor scrutiny

This complements a HIPAA-focused compliance project by demonstrating breadth 
across multiple regulatory/audit frameworks.

---
